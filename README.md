# Directory Core

Shared artist and venue records for the Artist Directory, Public Art Map, and future event products.

Publisher: Mostly Wanted

## Current Scope

- `mw_artist` canonical artist records
- `mw_venue` canonical venue records
- `mw_media` taxonomy for artist filtering
- shared admin menu grouping
- explicit visibility states for public and internal use
- reciprocal artist/venue relationships

## Notes

This plugin is intended to remain neutral at the product level so sibling plugins can evolve independently while sharing stable records.
